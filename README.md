# AI Spend Audit

A full-stack AI spend optimization platform built for startups to analyze and reduce AI subscription costs.

It audits AI tool expenses, recommends savings opportunities, generates AI-powered optimization summaries, captures leads, and provides shareable audit reports.

## Tech Stack

- React + Vite
- Node.js + Express
- MongoDB
- OpenRouter API
- TailwindCSS
- Recharts

## Features

- AI spend input form
- Rule-based audit engine
- AI-generated summaries
- Lead capture modal
- Shareable public audit reports
- Savings visualization

## Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Key Decisions

1. MERN for fast iteration
2. Rule-based audit engine for defensible recommendations
3. OpenRouter for flexible AI summary generation
4. LocalStorage for form persistence
5. Recharts for quick analytics visualization
